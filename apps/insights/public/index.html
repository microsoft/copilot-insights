A SMALLER DATA FOOTPRINT

Metadata by design

Local evaluation has no sign-in and must remain on loopback. Production requires an Entra Insights.Admin app-role assignment for analytics, review APIs, and the admin MCP server. A public sign-in shell contains no reports.

What this view reads

Only a narrow projection of this project's sanitized collector file: operation type, validated model/tool labels, token counts, span durations, explicit outcomes, and validated trace/span, conversation, window/session, and tool-call identifiers. These identifiers are diagnostic metadata, not proof of an anonymous dataset. There is no raw-record endpoint.

What stays out

Reports exclude prompts, responses, source code, file paths, user identities, internal datasets, and private service connections. Assets are served locally, without analytics trackers or remote CDN scripts. Production sign-in additionally contacts Microsoft Entra; report and review requests go to this Insights service.

Two separate organizations

The Demo organization contains independently generated fictional examples and is available only in local evaluation. My VS Code organization reads the collector's configured organization only. The collector overwrites any client-supplied organization ID. The selector does not create tenants or provide shared-service authorization.

Project context

The companion extension reads only the project identifier selected for the first workspace folder. A separate persisted registry joins the native window ID to that project. This is registration metadata, not a new native Copilot event or an authorization boundary. Missing, unregistered, and unsafe boundary-crossing activity stays unattributed. Cumulative metrics are not split between projects.

Your review decisions

Only a fixed status, signal ID, evidence count and newest evidence time, revision, source, organization ID, project key, and timestamp are saved. Free-text notes and reviewer identities are intentionally not collected. Decisions are scoped to the organization, project filter, and window length; evidence that arrives later is flagged for another look.

Know the limits

The UI is not a substitute for collector privacy qualification. Existing pipeline gaps remain. Fleet, live Entra, Azure, and privacy qualification must be completed for your environment. Do not enable real-user collection without approval.
