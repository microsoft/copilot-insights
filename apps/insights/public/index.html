A SMALLER DATA FOOTPRINT

Local by design

This is a local evaluation workspace, not a shared or authenticated team service.

What this view reads

Only a narrow projection of this project's sanitized collector file: operation type, validated model/tool labels, token counts, span durations, explicit outcomes, and trace correlation. There is no raw-record endpoint.

What stays out

Prompts, responses, source code, file paths, identities, internal datasets, and private service connections. No browser trackers, external fonts, uploads, or third-party API calls are used.

Demo means demo

The synthetic source is generated independently on this machine. It is never mixed with the collector source or presented as real usage.

Your review decisions

Only a fixed status, evidence fingerprint, revision, source, and timestamp are saved locally. Free-text notes and reviewer identities are intentionally not collected. Decisions are scoped to the exact evidence snapshot; changed evidence needs a new review.

Know the limits

The UI is not a substitute for collector privacy qualification. Existing pipeline gaps remain. Real-client and Azure validation, shared authentication, and organization-level authorization are not implemented here. Do not publish this service or enable real-user collection without approval.
